# RealtimeStack 1.1.2-beta

Historical release notes use current RealtimeStack product terminology. Previously published binary/package contents and filenames remain immutable; consult the [major-version upgrade guide](../upgrading-to-realtimestack-2.md) for their original identities and replacements.

This coordinated patch release publishes the gateway application and container, Helm chart, eighteen NuGet packages, browser SDK, automation scripts, and reference applications at `1.1.2-beta` from [Cormier-Solutions-LLC/RealtimeStack](https://github.com/Cormier-Solutions-LLC/RealtimeStack).

## Changes

- Upgrade the Go example and the Rails, Swift, and PHP proxy builds to `golang.org/x/net` v0.62.0 to address CVE-2026-78661.
- Align the Go reference module identity and default Helm image repository with RealtimeStack.
- Supersede the unpublished `1.1.1-beta` candidate after its container scans blocked publication.

- Adopt the renamed RealtimeStack repository in package documentation, npm source/issue metadata, NuGet Trusted Publishing setup instructions, and release titles. Helm chart metadata points to the renamed repository.
- Regenerate browser assets and synchronize version defaults, dependency lockfiles, bootstrap examples, and all ten reference application changelogs.
- New container revisions publish to `ghcr.io/cormier-solutions-llc/realtimestack-gateway`; existing deployments can update their configured image repository when upgrading.
- Publish new immutable package revisions with source and project links pointing to the renamed repository.

## Compatibility and upgrade notes

- NuGet package IDs remain `RealtimeStack.*`. CLR namespaces, assembly names, static asset paths, and the npm candidate name remain `RealtimeStack.*`, `/_content/RealtimeStack.Browser/`, and `@realtimestack/client`, respectively.
- The wire protocol remains `1.0` with WebSocket subprotocol `realtimestack.v1`; this repository rename does not change runtime APIs or deployment identities.
- Update Git remotes to `https://github.com/Cormier-Solutions-LLC/RealtimeStack.git`. Package consumers can update the coordinated package set to `1.1.2-beta`.
- NuGet Trusted Publishing must authorize this repository, `packages.yml`, `package-production`, and the `RealtimeStack.*` scope. An existing active policy is bound to permanent GitHub repository and owner IDs.
- npm publication remains an explicit opt-in; the browser SDK is distributed through `RealtimeStack.Browser` and the verified npm tarball in the package candidate.

## Release integrity

- Publication requires successful main-branch CI for the exact source commit.
- NuGet packages, the gateway image, and the public Helm chart use the same coordinated version. Publication promotes the verified candidate bytes without rebuilding.
