# Cormier Realtime 1.1.0-beta

This coordinated feature release updates NuGet, browser/npm, the gateway, Helm, bootstrap version defaults, and reference applications to `1.1.0-beta`.

## Changes

- Replace the six `Cormier.Realtime.*` NuGet IDs with `Realtime.*`, preserving existing CLR namespaces and assembly names.
- Add `Realtime.Plugins.Persistence` and PostgreSql, MySql, MariaDb, SqlServer, AzureSql, Oracle, Sqlite, Db2, CockroachDb, and Snowflake adapter packages for replay records, notifications, and task snapshots.
- Add `Realtime.Config` with explicit registration, disabled first-run configuration templates, setup inspection, custom setup steps, and idempotent missing-table initialization.
- Add optional session-scoped persistence reads/acknowledgments and separately authenticated private worker writes. Add browser/TypeScript and portable .NET clients, shared example controls, and reader proxy routes in all ten server-language adapters.
- Forward optional persistence configuration through the shared PowerShell/Bash bootstrap contract and validate Secret references and topology before deployment.
- Add Helm Secret references, database egress, private worker ingress, a revision-specific schema setup Job, and guarded SQLite PVC/Recreate deployment.
- Update the standalone runtime/compiler to .NET 10.0.14 to resolve the known compiler advisory.

## Compatibility and upgrade notes

The existing WebSocket protocol remains v1. All durable features are opt-in; persistence does not automatically capture every WebSocket publish or execute imports. Hosts must run workers outside browser/request lifetimes, persist discoverable task IDs, allocate ordered durable sequences, and handle retry-safe business side effects.

Migrate the entire NuGet dependency graph to the new IDs; do not install both identity families together. CLR namespaces, static asset paths, browser filenames, and protocol identity remain unchanged. Configure NuGet ownership and Trusted Publishing for `Realtime.*` before promotion. Deprecate old IDs only after successful replacement publication, preserving historical versions.

The shipped hosts include SQLite, PostgreSQL and CockroachDB connection factories. Other database packages require a custom host/image registering its selected ADO.NET driver. All ten adapters build; engine-specific runtime qualification remains necessary for providers not exercised with a live database. See [configuration](../configuration.md), [integration](../persistence-integrations.md), and [persistence semantics](../persistence.md).

First-time database setup is explicit and creates a missing record table; it never drops, resets, or upgrades existing tables. Supply connection strings and worker tokens through secret configuration. Public reader routes use authenticated session scope, while worker-write routes require a separate privileged token and are omitted from reference browser proxies and public chart ingress.

For Helm, use an external database for HA. SQLite requires a preinitialized existing PVC, one non-HA replica, disabled autoscaling and Recreate rollout. Database setup Jobs are opt-in and external-database-only. Build/publish the matching gateway image before deploying this new chart version.

## Release integrity

Publication requires successful main-branch CI for the exact source commit, the protected release environment, and configured registry ownership. Candidate creation does not publish packages or deploy the cluster. The eighteen NuGet packages, browser/npm package, gateway image and chart share the coordinated version; immutable candidate hashes and source commit identify the exact build.
