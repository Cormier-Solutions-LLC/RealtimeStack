# RealtimeStack 2.0.3-beta

This major beta completes the public RealtimeStack identity across .NET assemblies and namespaces, browser and npm APIs, scripts, Helm assets, configuration, routes, metrics, documentation, and reference applications.

## Changes

- Correct the unique dependency order for all 22 NuGet packages and rehearse all 44 package and symbol uploads during candidate validation.

- Validate the renamed Rust, Swift, and Python adapters with their pinned formatters and refresh the Laravel lockfile content hash without changing dependencies.
- Document preservation of existing relational persistence table names during migration.

- Preserve public handler constructors under trimming and enable Native AOT analysis for the common .NET 10 logging integration. Build both logging target frameworks before clean-consumer packaging.

- Authenticate pinned CI image pulls with the repository's existing Docker Hub credentials, including the package-candidate Redis service. This corrects the anonymous registry quota that blocked the unpublished `2.0.0-beta` candidate.

- Rename public APIs and distributable identities to RealtimeStack; keep the existing `RealtimeStack.*` NuGet IDs and publish new immutable major revisions.
- Add `RealtimeStack.Plugins.Logging` as the common error-handler integration and Bugsnag, Serilog, and Log4net adapters.
- Include package-specific upgrade guidance in every NuGet README and a central migration guide.
- Update repository links, release branding, generated browser assets and integrity manifests, and reference applications.
- Include the Go networking security fixes verified while preparing the earlier unpublished beta candidates.

## Upgrade

Follow [Upgrade to RealtimeStack 2](https://github.com/Cormier-Solutions-LLC/RealtimeStack/blob/main/docs/upgrading-to-realtimestack-2.md). NuGet updates dependencies; application imports, registration calls, configuration, asset URLs, routes, and operational selectors require the documented migration. Upgrade clients and gateways together. Envelope schema version remains `1.0`; the default subprotocol is now `realtimestack.v1`.

Prior immutable package versions retain their original contents. The prepared `1.1.1-beta`, `1.1.2-beta`, `2.0.0-beta`, and `2.0.1-beta` candidates were not published. The `2.0.2-beta` gateway, chart, and SDK were released; its NuGet promotion stopped before uploads. Use this complete revision for NuGet packages.

## Release integrity

Publication requires successful main-branch CI for the exact commit and promotes the verified package and container bytes without rebuilding. npm registry publication remains conditional on ownership and credentials for `@realtimestack/client`; the verified npm tarball is built with every candidate.
